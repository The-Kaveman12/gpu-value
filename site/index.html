#

How this works

Value

FPS per $100 = the card's average frame rate across Tom's Hardware's game suite at the chosen resolution and settings, divided by its price, times 100. Higher is better. “Mixed” weights raster 70% and ray tracing 30%.

Prices

Pulled from the eBay Browse API every few hours: US Buy It Now listings from sellers with at least 97% positive feedback. Titles are matched to the exact model (a 5070 never counts as a 5070 Ti), and junk listings like empty boxes and parts-only cards are dropped. The price shown is the median of the 5 cheapest matches, shipping included, so one bait listing can't skew it.

Performance

Real game benchmarks from Tom's Hardware's GPU Benchmarks Hierarchy, all run on one test system. Only cards in that hierarchy get a value score. Every other card is still listed with full specs.

Specs

From the TechPowerUp GPU Database, via the open RightNow GPU Database (Apache-2.0). Laptop, integrated, console and data-center parts are excluded.

Not affiliated with any retailer or manufacturer. Prices change constantly, so check the listing before you buy.
